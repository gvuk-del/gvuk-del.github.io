The app only accesses the owner's own Google account data, and only the data the owner approves on Google's consent screen.

The data is used only to run the owner's own personal tools and automations. It is not used for advertising, profiling or any other purpose.

How the data is stored

Access tokens and any data the app handles are kept only on the owner's own computer or accounts. Nothing is stored on any public server.

Sharing

Google user data is never sold, shared or transferred to anyone.

This app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
